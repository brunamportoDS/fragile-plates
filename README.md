# Fragile Plates

A data essay from the Women in Data 2026 Datathon, What's Cooking? track. When a country's biggest crop supplier disappears, whose plate breaks first, and how large is the calorie gap?

Data: FAOSTAT Detailed Trade Matrix and Food Balances, bulk downloads retrieved September 2026.

The page is a single HTML file. Open `index.html` in a browser, or read it on GitHub Pages.
